Connect to Firebase 🔥
One-time setup — karke rakh lo, phir kabhi nahi karni. Bas 5 minute lagenge!
Step 1
Firebase project banao
console.firebase.google.com pe jao → "Add project" → Project naam rakho (e.g. "nextgen-social") → Continue → Continue → Create project
Step 2
Web app register karo
Project open karo → "</>" icon (Web) click karo → App nickname rakho → "Register app" → firebaseConfig wala saara code copy karo (apiKey se lekar measurementId tak)
Step 3
Realtime Database enable karo
Left sidebar → Build → Realtime Database → "Create Database" → Location: us-central1 → "Start in test mode" choose karo → Enable
Step 4
Config yahan paste karo
firebaseConfig object se values copy karke neeche fill karo:
⚠️ databaseURL field khali hai toh Firebase console → Realtime Database → copy the URL
Step 5
Site host karo (FREE) — GitHub Pages
1. github.com par account banao (agar nahi hai)
2. New repository banao → naam rakho "nextgen-social" → Public → Create
3. "uploading an existing file" click karo → ye HTML file drag karo → Commit
4. Settings → Pages → Branch: main → Save
5. Link milega: https://yourusername.github.io/nextgen-social/
6. Woh link dost ko bhejo — wo khud account banayega!
